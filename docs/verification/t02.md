## Hook file: `.kiro/hooks/provenance.json`

```json
{
  "version": "v1",
  "hooks": [
    {
      "name": "provenance-file-save",
      "trigger": "PostFileSave",
      "matcher": "^(?!.*docs[\\\\/]provenance[\\\\/]).*$",
      "action": { "type": "command", "command": "node scripts/provenance/record.mjs --event file-save --stdin" },
      "timeout": 10
    },
    {
      "name": "provenance-agent-stop",
      "trigger": "Stop",
      "action": { "type": "command", "command": "node scripts/provenance/record.mjs --event agent-stop --stdin" },
      "timeout": 10
    }
  ]
}
```

(`description` fields omitted here; they are in the file.) Format taken from kiro.dev/docs/hooks and /hooks/types (read 2026-11-27).

Loop guard, two layers: the matcher is a negative lookahead that skips any path containing `docs/provenance/`, and `record.mjs` itself refuses such a path.
